- 两台 BOOM 4 已在 Windows 配对，用户报告电脑 PartyUp 播放成功。
- 主音箱 CPP 状态读取成功，原始音频选项为同播 `0x00`。
- 设置主左／副右时，主音箱配置 `0x50` 精确回读通过；副音箱 AddReceiver 声道 `2` 指令收到匹配回复。
- 用户在新版工具中应用主左／副右并播放测试音，确认先只有主音箱发低音，再只有副音箱发高音。
